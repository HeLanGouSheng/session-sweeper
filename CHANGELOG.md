# Changelog

## 0.1.0

First release.

- One list of local Claude Code and Codex conversations, grouped by folder, with real disk usage.
- Search by what you or the assistant said.
- Plain-text preview of a conversation.
- Complete deletion of a Claude Code conversation: transcript, data folder, file snapshots, environment data, telemetry files, temp folders, input-history lines. Moved to the Recycle Bin / Trash by default.
- Complete deletion of a Codex conversation through `codex delete`, including the review threads that command leaves behind.
- Conversations in use are detected and skipped.
- Clean-up of leftovers from conversations deleted earlier.
- English and Simplified Chinese.
